# How to Compile

first compile and install MX2:

https://github.com/lostjared/libmx2

then:

```bash
git clone https://github.com/lostjared/SpaceRox.MX2.git
cd SpaceROx.MX2
mkdir build && cd build
cmake ..
make -j$(nproc)
./SpaceRox
```
